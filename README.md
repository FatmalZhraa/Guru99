# Guru99 Manual Testing Project

## Overview
This repository contains a complete Manual Testing project for the Guru99 Banking Demo application.  
The project demonstrates real-world QA activities including requirement analysis, test planning, test case design, defect reporting, and validation testing.

- Guru99 Banking Demo Project  
  https://demo.guru99.com/V1/
